# B 站视频 / 专栏图文发布

MultiPush 支持两类 B 站内容：

- **B 站视频投稿**：使用已导出的 MP4 成片，上传 16:9 封面，填写标题、简介、标签和分区后提交审核。
- **B 站专栏 / opus 图文**：把渲染后的长图文写入 B 站新版图文编辑器，可保存草稿或公开发布。

两类内容共用同一个 B 站账号登录态，但发布链路完全不同。

## 入口

1. 在「智能渲染」勾选「B站」，生成 B 站排版。
2. 进入「发布管理」→「B站」，选择对应的渲染记录。
3. 未连接账号时点击「扫码连接 B 站」，使用哔哩哔哩 App 扫码。

视频内容渲染结果为 16:9 视频页；普通文章/图文内容渲染结果为 B 站专栏/opus 图文。

## 账号连接

- 使用 B 站官方登录页的扫码登录，不接收账号密码。
- 登录态按用户加密保存到 `bilibili_accounts`，服务重启后继续复用；过期后重新扫码。
- 浏览器路径默认自动探测 Chrome / Edge / Chromium，可通过 `BILIBILI_BROWSER_PATH` 指定。
- 调试登录页时可设置 `BILIBILI_HEADLESS=0` 显示浏览器窗口。

## B 站视频投稿

发布页需要：

- 一段视频成片（MP4 / MOV 等 B 站支持的格式）；
- 一张 16:9 封面图（建议 1920×1080 或 1280×720）；
- 标题 ≤80 字；
- 简介 ≤2000 字；
- 标签 1–10 个，逗号分隔；
- 分区可自动匹配，也可手动选择。

服务端链路：

1. 上传封面到 B 站；
2. 申请 UPOS 上传凭据；
3. 开启分片会话；
4. 逐片上传并封口；
5. 调用 `add/v3` 创建稿件。

提交成功后会得到 `BV` 号，状态为「审核中」。审核通过并公开后，可在发布记录里点「检查视频状态」更新为「已发布」。B 站 Web 投稿接口可能随平台调整，遇到风控或参数变化会停止并提示，不会自动重试提交。

## B 站专栏 / opus 图文

发布页支持：

- 标题 ≤40 字（B 站专栏建议长度；超过会截断并提示）；
- 保存草稿：写入 B 站新版图文编辑器并保存，不公开；
- 公开发布：保存草稿后点击「发布」，并尝试捕获 `create/opus` 成功信号。

正文图片从渲染结果读取：本站 `/uploads/` 图片直接读取文件，外部图片尝试下载。图片先通过 B 站编辑器真实使用的 `x/dynamic/feed/draw/upload_bfs` 接口上传（WBI 签名 + `bili_jct`，字段 `file_up`/`biz=new_dyn`/`category=daily`），确认 CDN 可读后，再用合成 paste 事件把正文 HTML 和 B 站图床图片一次性写入编辑器。

- 正文和图片在同一个 paste 事件中写入，避免丢失图片节点；
- 上传接口失败时才走剪贴板兜底；剪贴板写入前必须聚焦编辑器，并通过轮询 `img` 数量确认节点出现；
- 失败信息包含是上传接口、CDN 就绪、图片节点、安全验证中的哪一步，不再只有「未能写入」；
- 图片位置由正文中的占位标记恢复；图片上传失败走剪贴板兜底时仍会追加到末尾，复杂图文建议发布前在 B 站编辑器确认。

图文发布结果不明确时会标记为「结果待核实」，并阻止同一篇内容立即重复提交。请先到 B 站创作中心检查，再选择「已发布」并填写公开链接，或「未发布」解除限制。

## 手动兜底

自动流程失败时，发布页仍提供：

- 「打开发布页」：打开 B 站视频投稿页或图文编辑器；
- 复制标题 / 简介 / 标签 / 图文 Markdown；
- 在 B 站创作中心手动上传或粘贴。

手动发布不会影响系统已有记录；需要时可在发布记录里人工核实并关联链接。

## 已知限制

- B 站视频 Web 投稿接口不是公开稳定 API，平台改版或风控可能导致上传失败；系统只做一次提交，不会自动重复投稿。
- 视频审核由 B 站控制，审核中/未公开时状态查询可能暂时返回「未公开」；以创作中心为准。
- 图文正文和图片写入仍依赖 B 站新版编辑器；上传接口或编辑器改版会停止并给出阶段化诊断，不会自动重复发布。
- 正文图片目前集中追加，复杂图文建议发布前在 B 站编辑器调整图片位置。
- 剪贴板兜底依赖浏览器焦点；正常路径优先走图片上传接口，不依赖系统剪贴板。
- 不支持 B 站动态短图文；当前「B 站图文」专指专栏/opus 长图文。
- 不绕过滑块、验证码、短信验证或平台风控。

## 验证建议

1. 先用一篇带 **3 张以上正文图片**的无敏感内容短文测试图文草稿，确认标题、正文和图片都进入 B 站编辑器。
2. 保存草稿后重新打开该草稿，确认 3 张图片仍在正文中，再把测试草稿删掉。
3. 再用一个短 MP4 和 16:9 封面测试视频投稿；提交后到创作中心确认稿件。
4. 不要用正式内容做第一次联调；视频投稿会产生真实稿件并进入审核。
