# 小红书：仅保留手动发布

小红书自动登录、登录状态检查、图片上传和自动提交均已停用。发布中心仅显示停用说明和本地历史记录，不会打开小红书浏览器。

服务启动时清除系统保存的小红书会话。旧网页或直接 API 调用的登录、发布及自动核实请求统一返回 `410 xiaohongshu_automation_disabled`；查询历史记录和删除本地连接仍可使用，均不访问小红书。

## 现在如何发布

1. 在渲染工作台生成小红书卡片和文案。
2. 下载卡片图片、ZIP 和文案。
3. 使用小红书官方 App 或创作中心手动上传、检查并发布。

原文、素材、排版和历史记录保留。历史结果不确定时，请到官方客户端核实，系统不会自动重发。

## 验证

```bash
npm run typecheck
npm test
npm run build
node scripts/smoke-xiaohongshu-publish.mjs
```

测试覆盖旧接口无法触发浏览器操作、已存会话清除、历史数据隔离，以及停用页面不请求账号检查、二维码或发布接口。旧浏览器驱动文件仅供历史单元测试使用，生产应用不再实例化或挂载该服务。
