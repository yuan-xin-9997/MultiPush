## 已实现

- pnpm workspace：桌面界面、共享类型、数据库、发布引擎。
- React/Vite开发入口与Tauri壳，Windows启动脚本。
- JSON行协议；stdout只输出协议消息，Pino日志写入stderr。
- SQLite WAL、外键、user_version迁移与批量任务事务。
- 内容快照固定在任务创建时，后续修改原内容不会改变已创建任务。
- 公众号和知乎等八个平台的能力范围注册；不可用能力在UI明确标注。
- 独立账号Profile、打开登录窗口、关闭窗口、本地截图。
- 本地素材存在性预检、取消、排期时间存储。
- 未确定的远端发布结果进入人工核对状态。
- 开发RPC仅允许本机同源JSON请求；正式桌面通信使用stdio。
- 知乎草稿保存、独立字段确认、刷新回读、草稿URL检查点、重复提交保护，已接入任务界面。
- SQLite v2迁移：持久化草稿链接。草稿保存成功状态为`draft_saved`，区别于公开发布成功。
