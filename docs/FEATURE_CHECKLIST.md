## 正在实现

- [x] 知乎话题：使用内容标签，最多5个，名称精确匹配，等待话题保存响应；两个话题的真实草稿保存及刷新回读通过。
- [x] 知乎草稿列表：通过编辑链接中的草稿ID与列表标题核对，已接入保存成功前校验；最多检查20批列表加载，超出范围要求人工核对。

- [x] 知乎Markdown草稿真实验证：标题层级、加粗/斜体样式、列表、引用、代码块均回读通过。知乎使用带样式的span及嵌套pre，已按实际结构校验。
- [x] 知乎正文图片及封面适配：Markdown+单张正文图片+封面真实集成验证通过；分别等待正文/封面保存请求，刷新回读正文、结构、媒体和封面。正文图片最多20张，PNG/JPEG、单张10MB；多张与极限数量仍需专项验证。
- [x] 本地素材选择与复制托管：Tauri 支持正文图片多选和封面单选，按 SHA-256 复制到数据目录 `assets/`；整批预验证、去重、防覆盖与路径逃逸、删除原文件后的任务预检均有自动测试。
- [x] 多图边界自动专项：覆盖0/1/3/20/21张、PNG/JPEG签名、10MB精确边界、伪装格式和顺序上传。真实平台的多图与慢网络仍待显式授权验证。
- [x] 公众号/知乎文章草稿异步队列：支持立即入队、到期自动领取、默认全局并发2、同账号串行、等待阶段取消及指数退避内核。普通 pending 任务不会自动执行；进入远程写入后禁止取消，结果未知只转人工介入、不自动重试。
- [x] 队列稳定化第一阶段：数据库v3持久化尝试次数、下次执行时间和失败分类；可重试错误按1秒/2秒退避且跨重启恢复，unknown/permanent不自动重试。同数据目录使用owner/PID/主机元数据的原子锁保证单引擎实例，仅回收同机且PID明确不存在的遗留锁。
- [x] 队列稳定化第二阶段：本地预检、账号草稿会话和远端回读阶段消息持久化，同一草稿地址检查点去重；远端写入前支持取消运行中任务，进入写入后拒绝取消。应用关闭会将本地阶段落为已取消，并等待外部写入落入成功或人工介入终态后再关闭数据库；新增 `task.events` 历史事件RPC。
- [x] 队列细粒度可观测性：公众号、知乎、小红书图文和抖音私密视频草稿统一上报会话、素材上传、字段填写、隐私设置、保存及远端回读事件；数据库v5持久化阶段和数量进度，任务页提供2秒刷新事件时间线及等待/执行/需处理/完成汇总。
- [x] 公众号/知乎登录态只读检测和用户介入：数据库v4持久化检查状态、时间和消息；只信任平台HTTPS域名及明确页面信号。验证码、安全验证、网络异常或信号冲突均保守转人工处理，不误判为登录过期。
- [x] 跨机器内容与图片迁移：version 2便携归档使用SHA-256去重内嵌PNG/JPEG，导入后重建本机托管路径；不包含账号、任务、Cookie或视频。桌面端通过原生文件路径读写最大70MB归档，既有文件拒绝覆盖；网页模式仅保留700KB小包调试降级。
