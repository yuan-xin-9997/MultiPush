# 少数派（Matrix）登录与文章发布

状态：已实现并通过模拟测试与发布页回归；尚未使用真实少数派账号完成扫码、草稿和正式发布的端到端验证。

在发布中心切换「少数派」，用微信扫描系统展示的少数派官方登录二维码并确认登录。也可在渲染工作台的少数派结果中选择「发布到少数派」。当前支持 Matrix 社区文章，提供保存草稿和立即发布。

## 登录状态

少数派网页版使用微信扫码登录。系统打开 `https://sspai.com/login`，点击「其他方式」中的微信入口，读取页面上的官方二维码；扫码完成后读取浏览器中由少数派写入的登录令牌（`ssToken`），再用 `GET /api/v1/user/info/get` 确认账号。无需手机号、短信验证码或少数派密码，不处理或保存用户密码。

每个 MultiPush 用户连接一个少数派账号，浏览器 context、登录请求与发布记录按用户隔离。已验证的 Cookie / localStorage 状态使用 AES-256-GCM 加密后写入 `sspai_accounts`，加密绑定 MultiPush 用户 ID。账号 ID 用于重复提交判断，不能仅用昵称识别账号。

密钥位于 `DATA_DIR/.sspai-session-key`，与微信公众号、知乎、抖音的密钥及 JWT 密钥分别保存。备份 SQLite 和数据目录时须包含此密钥。重启后可恢复登录；少数派令会话失效时提示重新扫码，不会退出 MultiPush。断开连接只删除系统内的会话，不删除少数派草稿和文章。状态查询最多缓存五分钟，实际提交前再次检查登录状态。二维码有效期五分钟，过期会关闭浏览器 context。

服务器沿用现有 Playwright Chromium 运行库。可设置 `SSPAI_BROWSER_PATH`，也会使用现有 `WECHAT_BROWSER_PATH` / `CHROME_BIN` 及系统 Chrome/Chromium 路径。登录初始化立即返回 `202` 和登录请求 ID，浏览器启动、二维码获取及扫码检查在后台执行，轮询接口只读取当前状态，避免慢网页阻塞公网请求。遇到安全验证或登录页拒绝时显示原因，不自动破解验证码或绕过验证。

## 正文与核验

- 使用当前用户保存的少数派独立排版；原文已修改或删除时，要求重新生成排版。
- 标题 1–32 字，正文 HTML 最多 1 MB、图片最多 100 张。支持每张最多 10 MB 的 PNG/JPEG/GIF/WebP；题图可选。当前不自动发布视频、音频、iframe 和 SVG。
- 正文图片先校验素材归属与实际文件格式，外链图片按公网 DNS 校验后下载，不携带登录凭据、不访问内网。图片通过少数派上传凭证上传到其七牛图床，正文最终只接受 `cdnfile.sspai.com` 图片地址。
- 使用少数派原生 HTML 结构：标题层级、列表、引用、代码块、表格、链接和图片 `figure`。编辑器保存后回读文章，核对标题、正文文字、图片数量与路径、列表、链接、代码和表格行数；正文不一致时停止正式发布，保留草稿供检查。
- 草稿通过 `POST /api/v1/matrix/editor/article/add` 创建，正文与题图通过 `/matrix/editor/article/update` 保存。正式发布使用同一接口将文章类型置为立即发布，并回读确认文章状态；接口受理本身不作为成功依据。
- 「新手上路」账号的前 3 篇社区内容可能需要人工确认后才公开展示。系统会把文章标记为已发布并提示平台可能仍在审核，不会等待审核状态。

同一账号、原文、模式、实际标题、排版、标签和图片内容参与幂等判断。保存草稿和正式发布分别记录；结果不确定或服务重启中断的任务不自动重试。已知在发布前失败且存在草稿时，用户再次提交会优先恢复原草稿；若草稿状态、标题或内容被外部修改则停止，避免覆盖编辑或重复文章。

## 结果待核实后的继续操作

提示旁的「核实并继续」以及发布记录中的「核实结果」可打开处理入口：

- 「重新自动核实」在后台只读检查少数派文章/草稿。只有文章编号、标题和状态均匹配时才自动关联为已发布；仍有草稿或状态无法确定时继续保留待核实，并允许人工选择结果。
- 「我已核实，未发布」经确认后解除限制，允许再次提交；已有草稿会优先复用。确认本身不触发发布，用户仍需再次选择立即发布。核实有误可能导致重复发布，因此弹窗明确提示这一风险。
- 「我已核实，已发布」填写 `https://sspai.com/post/文章编号` 链接后，按人工核实结果标记已发布并关联链接，不再次发送文章。链接会去除分享参数。

核实动作和结果在独立记录表持久保存，发布记录可展开查看；重新提交和服务重启不会清除核实记录。接口按用户隔离，处理中的任务和已变化的状态不能被并发覆盖。

## API

所有接口均要求 MultiPush Bearer JWT，响应使用 `Cache-Control: no-store`。少数派会话失效返回 `409 sspai_session_expired`；安全验证返回 `409 sspai_security_check`。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/sspai/account` | 查询账号状态 |
| `POST /api/sspai/login` | 获取少数派微信登录二维码 |
| `GET /api/sspai/login/:id` | 查询扫码/确认状态 |
| `DELETE /api/sspai/account` | 断开连接 |
| `POST /api/sspai/publications` | 提交 `{renderId, mode: "draft"或"publish", coverMediaId?}` |
| `GET /api/sspai/publications` | 当前用户最近 50 条记录 |
| `GET /api/sspai/publications/:id` | 查询进度、草稿或文章链接 |
| `DELETE /api/sspai/publications/:id` | 删除草稿或失败记录：草稿会同步删除少数派后台草稿；已发布、处理中和结果待核实记录不可删除 |
| `POST /api/sspai/publications/:id/resolve` | `{action:"check"}` 异步复查；`{action:"not_published"}` 人工确认未发布；`{action:"published",articleUrl}` 人工关联已发布文章 |

## 参考与验收

- 少数派网页登录、编辑器与矩阵接口通过 `https://sspai.com/login`、`https://sspai.com/write` 的公开前端脚本确认；这些网页接口和编辑器没有稳定性承诺，少数派改版后可能需要更新适配。
- 自动化测试使用隔离数据库和合成凭据，不会向真实少数派账号发布文章，覆盖用户隔离、会话加密与重启恢复、标题/素材校验、幂等、内容准备与回读核对、结果待核实处理。
- 页面交互回归可先运行 `npm run build:web`，再运行 `node scripts/smoke-sspai-publish.mjs`；该脚本使用独立本地 API fixture，检查扫码状态、草稿/发布按钮、确认弹窗、错误与不确定状态，以及桌面和手机宽度布局，不访问真实少数派账号。
- 真实验收需用微信扫码连接后，新建一篇包含图片、列表、链接、代码和表格的草稿，在少数派编辑器中检查实际显示，再由用户发起正式发布并核对文章链接。

## 已知限制

- 少数派网页登录依赖微信扫码；微信侧若要求额外确认或限制了第三方扫码，系统会停止并提示，不支持手机号/邮箱密码登录。
- 不发布视频、音频、SVG、iframe 或付费文章设置；不自动选择少数派标签推荐列表，只使用原文标签（最多 5 个）。
- 平台可能对内容进行审核、裁剪或改写图片地址；系统只核对保存后的结构，发布后的展示以少数派为准。
