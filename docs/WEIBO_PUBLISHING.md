# 微博渲染与发布

> 手机验证码登录：在发布页点击「手机验证码登录」，通过 `passport.weibo.com` 的「验证码登录」完成连接；不保存密码。出现安全验证时请改用扫码。

## 草稿

微博网页端没有草稿箱接口，发布页的「保存草稿」只把完整文案/图片快照保存在 MultiPush 本地，状态为 `draft`；需要发布时到渲染页复制文案、下载图片后手动发布。系统不会把草稿提交成一条仅自己可见的微博。


状态：渲染、扫码登录和发布流程已实现并通过模拟测试；真实微博账号扫码登录已验证，正式发布尚未用真实账号完成端到端验证（当前环境没有可用微博账号）。

## 渲染

微博以短图文流呈现，没有独立文章标题输入框。MultiPush 将内容整理为一条完整微博文案：

- 第一行使用内容标题；
- 正文使用纯文本，最多 2000 字，超出会截断并提示；
- 正文中的链接会保留为「链接文字 + 完整 URL」，避免发布后只剩链接文字；
- 正文超过单条 2000 字时不再截断，而是按段落/句子拆成微博串：第一条包含标题，最后一条包含话题，后续内容以评论接龙发布；
- 发布页显示微博串条数、完整分条文案和截断旧记录警告；
- 标签转换为微博双井号话题，例如 `#效率# #工具#`；
- 正文图片最多保留 9 张，超出部分不会上传并在渲染结果中提示；
- 视频暂不进入微博发布，正文中的视频会被忽略并提示；
- 提供微博文案 TXT、微博图文 HTML 和 JSON 下载。

微博预览使用信息流卡片模拟：作者、标题、正文、1–9 图网格、话题和互动栏。发布前检查会核对标题、单条微博长度（多条时取最长一条）、图片数量和原文版本。

## 登录

在「发布管理 → 微博」点击「扫码连接微博」，系统打开微博官方登录页 `https://passport.weibo.com/sso/signin?entry=miniblog&source=miniblog`，读取官方二维码并展示在系统内。

- 使用微博 App 扫码并在手机上确认；
- 登录成功后先用 `m.weibo.cn/api/config` 读取当前 uid（`weibo.com/ajax/profile/info` 必须带 `?uid=`，否则返回 400「缺少必要参数」），再读取账号昵称；
- 扫码后页面提示「成功扫描，请在手机点击确认以登录」时，界面同步提示已扫码；
- 浏览器 Cookie/localStorage 使用 AES-256-GCM 加密保存，密钥位于 `DATA_DIR/.weibo-session-key`，加密绑定 MultiPush 用户 ID；
- 断开连接只删除本系统会话，不会退出微博其他设备；
- 会话过期时重新扫码；遇到安全验证停止操作。

真实扫码登录已在本地通过无头 Chrome 验证：二维码图片不会在加载完成前截屏；扫码后 4 秒内确认，Cookie 写入后即可读出 uid 和昵称。账号状态、二维码轮询和账号隔离由单元测试覆盖。

## 发布

1. 在渲染工作台生成微博排版；超过 2000 字时预览会显示「将发布为 N 条微博串」；
2. 发布管理 → 微博，选择排版；
3. 点击「发布到微博」并确认。

发布使用官方网页发布框：

- 定位微博发布框并写入标题、正文和话题；
- 通过文件输入上传最多 9 张图片；
- 点击「发送」，捕获 `POST /ajax/statuses/update` 响应；
- 只有响应 `ok=1` 且返回有效微博编号才标记已发布，并生成 `https://weibo.com/用户编号/微博编号` 链接；
- 提交后响应不明确、超时或服务重启时标记「结果待核实」，不自动重发；
- 遇到安全验证、登录失效或页面结构变化时停止操作。

发布记录的「核实结果」支持：

- 重新自动核实：读取 `ajax/statuses/show`，按微博编号确认；
- 我已核实，未发布：解除限制，允许重新提交；
- 我已核实，已发布：填写微博链接并关联，不会再次发布。

## API

所有接口要求 MultiPush Bearer JWT，响应 `Cache-Control: no-store`。微博会话失效返回 `409 weibo_session_expired`。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/weibo/account` | 查询账号状态 |
| `POST /api/weibo/login` | 获取官方登录二维码（202） |
| `GET /api/weibo/login/:id` | 查询扫码/确认状态 |
| `DELETE /api/weibo/account` | 断开连接 |
| `POST /api/weibo/publications` | 提交 `{renderId}` |
| `GET /api/weibo/publications` | 当前用户最近 50 条记录 |
| `DELETE /api/weibo/publications/:id` | 删除本系统的草稿或失败记录，不会操作微博；已发布、处理中和结果待核实记录不可删除 |
| `POST /api/weibo/publications/:id/resolve` | `{action:"check"}` 异步复查；`{action:"not_published"}` 人工确认未发布；`{action:"published",articleUrl}` 人工关联已发布微博 |

## 验证与限制

- 单元测试覆盖微博文案渲染、双井号话题、图片上限、会话加密、幂等、待核实处理和重启恢复。
- 页面回归：先 `npm run build:web`，再运行 `node scripts/smoke-weibo-publish.mjs`，使用隔离 fixture 验证扫码、发布确认、失败、待核实和人工核实流程，不访问真实微博账号。
- 真实登录页二维码已用本机 Chrome 验证；正式发布需要在有微博账号的环境中扫码后验证发布框、图片上传和 `statuses/update` 响应。
- 微博网页发布框和接口没有稳定性承诺，改版后可能需要更新选择器和响应解析。
- 不支持视频、长文章（头条文章）、定时发布、可见范围设置、带位置微博和微博抽奖等高级功能。
- 连续发布完全相同的内容可能被微博拒绝；系统按账号、原文、文案和图片生成幂等键，避免本系统重复提交。
