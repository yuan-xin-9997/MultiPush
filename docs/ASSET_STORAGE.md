# 图片本地托管（2026-09-10）

内容编辑表单新增“将图片复制到本地素材库”：填写正文图片和封面绝对路径后点击，校验 PNG/JPEG 文件头及单文件 10MB 上限，复制到当前数据目录的 assets 子目录。按 SHA-256 文件名去重，不移动原文件、不覆盖已有文件；遇到已有文件内容不一致则报错。

导入成功后表单替换为托管路径，需要再点击“保存内容”。已有任务的内容快照不变，需要新建任务才会使用新路径。导入后取消编辑会留下未引用素材，目前不自动删除，避免误删任务使用的图片。

Tauri 桌面端已支持原生图片选择对话框：正文图片可多选，封面单选，选择后立即托管并回填托管路径。浏览器开发模式受浏览器安全限制，仍保留绝对路径手工输入作为降级方式。

本轮未实现：视频托管、素材清理、打包导出图片及跨机器路径重建。JSON 导出仍仅包含路径，不打包素材。不要手动修改 assets 文件。

测试覆盖：字节保留、原文件保留、重复导入去重、删除原文件后托管副本仍可读、损坏副本不覆盖、错误格式和相对路径拒绝。未进行新的线上草稿写入或原生窗口交互测试。
