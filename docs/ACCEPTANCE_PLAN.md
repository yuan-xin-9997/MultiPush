- [ ] `npm ci` 成功。
- [ ] `npm run typecheck` 前后端 0 错误。
- [ ] `npm test` 全部通过。
- [ ] `npm run build` 生成 `web/dist` 与 `server/dist/index.js`。
- [ ] 生产服务监听 `0.0.0.0:34080`，`/api/health` 返回 ok。
- [ ] 浏览器标签页显示 MultiPush 图标，标题为“MultiPush · 多平台智能发布系统”。

## B. 用户系统

- [ ] 重复用户名/邮箱返回清晰错误。
- [ ] 退出后用错误密码登录失败，正确密码登录成功。
- [ ] 用户 A 看不到用户 B 的文档/知识库/渲染记录（API 或双浏览器验证）。

- [ ] 新建/重命名/删除知识库；删除后文档进入未分组。
- [ ] 全部内容 / 知识库 / 收藏 / 回收站筛选正确。

- [ ] 卡片左上角按类型显示「文章」「图文」「视频」角标；悬停时选择框出现在角标右侧，不遮挡角标。

- [ ] 单篇导出 Markdown / HTML / JSON 文件内容正确。

- [ ] 自动保存状态准确；Ctrl/Cmd+S 生效；离开提示未保存。

## D2. 图文内容

- [ ] 内容库「新建图文」创建 `gallery` 内容并进入 `/gallery/:id`；内容库卡片带「图文」角标并显示「N 张图」。

- [ ] 拖拽手柄或 ↑/↓ 调序成功并自动保存；刷新后顺序不变。

- [ ] 公众号贴图（≤20）、小红书（≤18）、抖音图文（≤35）渲染均识别全部图片；超过上限有提醒或按平台截取。
- [ ] MultiPush JSON 导出再导入仍为图文；复制图文、导出、删除到回收站正常。
- [ ] 旧数据库升级后原有文章/视频与子表数据不丢，可正常创建 `gallery`。
- [ ] 移动端 390×844 无横向溢出，图片工具栏可见。

## D3. 视频内容与剪辑

- [ ] 内容库「新建视频」创建视频内容并进入 `/video/:id` 工作台；视频内容带角标，图文编辑器打开视频内容会自动跳转。
- [ ] 一次上传一段或多段视频（MP4/WebM/MOV，单段 ≤200MB），进度可见，超限有提示；上传后进入时间线。
- [ ] 片段修剪：设入点/设出点（以播放位置为准）、数字输入、播放本段/整条预览；时间线自动保存。
- [ ] 片段上移/下移/删除；删除不删除素材；时间线总览条按时长比例展示。
- [ ] 标题/正文/标签自动保存；正文按空行分段；Ctrl/Cmd+S 生效。
- [ ] 导出成片：异步任务有进度；完成后成片可预览/下载并存入素材库；服务器无 ffmpeg 时给出明确提示且剪辑可保存。
- [ ] AI 创作可通过工具查看时间线、修剪/调序片段并导出；`GET/PUT /api/contents/:id/video*` 与导出接口按用户隔离（越权 404）。
- [ ] 回收站/复制：复制视频内容会复制时间线；彻底删除不影响素材库原视频。

## E. 素材库

- [ ] 图片、视频、PDF、文本类文档预览正常；Markdown 渲染预览，同文件夹相对图片（含 HEIC 转换图）能正确显示；Office 文档提示下载；下载文件名正确；复制链接可访问。
