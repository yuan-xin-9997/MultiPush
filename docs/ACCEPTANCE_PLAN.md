# MultiPush 验收计划

验收环境：Windows 本地 `npm run dev`，以及 Linux `/opt/MultiPush` 生产部署。

## A. 构建与基础

- [ ] `npm ci` 成功。
- [ ] `npm run typecheck` 前后端 0 错误。
- [ ] `npm test` 全部通过。
- [ ] `npm run build` 生成 `web/dist` 与 `server/dist/index.js`。
- [ ] 生产服务监听 `0.0.0.0:34080`，`/api/health` 返回 ok。
- [ ] 浏览器标签页显示 MultiPush 图标，标题为“MultiPush · 多平台智能发布系统”。

## B. 用户系统

- [ ] 注册新用户成功并自动登录。
- [ ] 重复用户名/邮箱返回清晰错误。
- [ ] 退出后用错误密码登录失败，正确密码登录成功。
- [ ] 用户 A 看不到用户 B 的文档/知识库/渲染记录（API 或双浏览器验证）。
- [ ] 刷新页面登录态保持；token 失效自动回登录页。

## C. 内容库

- [ ] 新建文档、编辑标题/正文、自动保存、刷新不丢。
- [ ] 新建/重命名/删除知识库；删除后文档进入未分组。
- [ ] 全部内容 / 知识库 / 收藏 / 回收站筛选正确。
- [ ] 搜索、排序、分页、卡片/列表切换正常。
- [ ] 收藏、复制、移动、软删除、恢复、彻底删除正常。
- [ ] 批量选择与批量导出 ZIP 正常。
- [ ] 导入 Markdown / HTML / TXT / MultiPush JSON；内容进入编辑器不丢失。
- [ ] 单篇导出 Markdown / HTML / JSON 文件内容正确。
- [ ] 多用户数据隔离。

## D. 编辑器

- [ ] 全屏类语雀布局，标题、工具栏、左右面板、正文层级清晰。
- [ ] H1-H3、粗斜体下划线删除线、颜色/高亮、列表/任务、引用、代码块、表格、分割线、链接、图片、视频、对齐、撤销重做均可用。
- [ ] 上传图片/视频成功并在正文显示；刷新后保留。
- [ ] 自动保存状态准确；Ctrl/Cmd+S 生效；离开提示未保存。
- [ ] 大纲点击定位；字数/阅读时间更新。
- [ ] 封面、标签、知识库、状态、收藏保存成功。
- [ ] 封面既能本地上传，也能从正文图片中选择；当前封面有标记，刷新后保留。
- [ ] 导入的 HTML 文档（contentJson 为空）打开不丢内容。
- [ ] 渲染按钮保存后跳转并带 contentId。

## E. 智能渲染

- [ ] 选择内容 + 八平台渲染成功，结果 tabs 与平台一致。
- [ ] 公众号预览为手机文章壳，排版与公众号移动端观感一致。
- [ ] 小红书生成封面/内容/结束卡，3:4，标题 ≤20 字，文案含话题；视频内容显示视频模式。
- [ ] 知乎预览为桌面文章页，Markdown/HTML 完整。
- [ ] 抖音预览为 9:16 竖屏信息流，文案含标题/正文/话题，复制与下载可用。
- [ ] 少数派预览为 Matrix 桌面文章页，Markdown/HTML 完整，可从结果直接进入少数派发布。
- [ ] 个人博客预览为 Halo 文章页，Markdown/HTML 完整，可从结果直接进入个人博客发布。
- [ ] 警告（标题超限/空内容等）正确显示。
- [ ] 复制公众号富文本粘贴到富文本编辑器保留样式；复制 Markdown 正常。
- [ ] 小红书卡片 PNG 导出为 1080×1440，文字清晰，ZIP 含文案与图片。
- [ ] “下载全部 ZIP”包含各平台内容且可解压。
- [ ] 渲染历史可加载、删除；刷新后可重新加载。
- [ ] 渲染选项（卡片风格、作者、标签）生效。

## F. 发布页

- [ ] 公众号官方扫码成功，刷新页面及重启后恢复会话；过期重新扫码，断开连接清除本系统会话。
- [ ] 知乎/微博/今日头条/百家号/豆瓣/掘金/抖音支持手机验证码登录；手机号与协议校验、验证码提交、会话保存正常；滑块或安全验证时提示改用扫码，不绕过。
- [ ] 草稿与正式发表明确区分；图片转存、封面、平台独立调整结果正确。
- [ ] 安全扫码可完成，核实微信发表记录后提供真实文章链接；重复提交不重复发表。
- [ ] 中断或重启标记结果待核实，不自动重试；用户间账号、素材、发布记录隔离。
- [ ] 少数派微信扫码可连接；草稿/立即发布回读核对通过，图片上传到少数派图床；结果待核实可自动复查或人工关联。
- [ ] 个人博客令牌连接、草稿/发布回读核对通过，图片上传到 Halo 附件库；结果待核实可自动复查或人工关联。
- [ ] 微博扫码可连接；微博排版首行为标题、正文和双井号话题正确，最多 9 图；发布后能关联微博链接，结果待核实可人工核实。
- [ ] 今日头条扫码可连接；头条排版标题 2–30 字、正文/图片/Markdown 下载正确；发布后能关联文章链接，结果待核实可人工核实。
- [ ] 公众号/知乎/少数派/个人博客草稿记录可删除，平台后台草稿同步消失，已发表记录不可删除。
- [ ] 抖音失败记录可清理，已发布和结果待核实记录不可删除。

- [ ] 内容库多选后可批量渲染，任务进度可见，完成后可打开对应渲染记录。
