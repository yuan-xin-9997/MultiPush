# MultiPush 使用指南

## 1. 注册与登录

打开系统地址（本地 http://127.0.0.1:34080 ，生产 http://192.168.0.111:34080 ），首次使用点击「注册账号」。用户名支持字母、数字、下划线或汉字；密码至少 8 位。注册后自动登录。

## 2. 内容库

- **知识库**：左侧可新建知识库，对文档分组。删除知识库不会删除文档，文档会移动到「未分组」。
- **全部内容 / 收藏 / 回收站**：顶部与侧栏可切换。删除的文档先进入回收站，可恢复或彻底删除。
- **搜索与排序**：支持按标题/摘要搜索，按最近更新、创建时间、标题排序。
- **卡片 / 列表视图**：视图偏好会保存在当前浏览器。
- **多选**：勾选文档后可批量导出 ZIP、批量删除或移动。

### 导入

点击内容库右上角「导入」，或将文件拖入内容区：

| 格式 | 说明 |
| --- | --- |
| `.md` / `.markdown` | 按 Markdown（GFM）解析，首个一级标题可作为文档标题 |
| `.html` / `.htm` | 保留常见排版，自动清洗脚本等危险内容 |
| `.txt` | 按空行分段 |
| `.json` | MultiPush 导出的单篇或 `{ contents: [...] }` 备份 |

单文件 ≤5MB，单次 ≤30 个。导入会进入当前知识库（未选择时进入未分组）。导入后首次打开编辑器时，系统会把 HTML 初始化到编辑器中并自动保存为结构化文档。

### 导出

- 文档卡片「更多」→「导出」：Markdown、独立样式 HTML、MultiPush JSON。
- 编辑器右上角「更多」→「导出 Markdown / HTML」。
- 内容库多选 →「导出 ZIP」，选择格式后打包下载。

导出的图片使用绝对地址（指向当前 MultiPush 服务），离线查看时请确保服务可访问；发布到平台前建议同时下载原图素材。

## 3. 编辑器

- 点击「新建文档」进入编辑器；标题直接输入。
- 工具栏支持标题、加粗/斜体/下划线/删除线、颜色/高亮、列表/任务列表、引用、代码块、表格、分割线、链接、图片、视频、对齐、撤销重做。
- **快捷插入**：在空行或空格后输入 `/`，可搜索并插入正文、标题、列表、引用、代码块、分割线、表格、图片、视频和链接；`↑`/`↓` 选择，`Enter` 插入，`Esc` 关闭。
- **图片/视频**：点击工具栏上传，或直接粘贴/拖入图片。上传后自动插入正文。
- **自动保存**：停止输入约 1 秒后自动保存；`Ctrl/Cmd + S` 立即保存。顶部显示保存状态。
- **左侧信息面板**：知识库、封面、标签、状态（草稿/待渲染）、收藏。
- **右侧大纲**：显示 H1-H3，点击可定位。
- 完成后点击顶部「渲染」保存并进入渲染工作台。

## 4. 智能渲染

1. 选择要渲染的文档。
2. 勾选平台（可多选）：微信公众号、小红书、知乎、抖音。
3. 选择小红书卡片风格（清新/暖阳/醒目），确认作者/账号名。
4. 点击「开始渲染」。

渲染结果页：

- 顶部平台 Tab 切换，每个平台有独立的模拟预览。
- 右侧/下方展示字数、图片数、视频数、标题长度与平台限制、排版警告。
- 历史记录可随时重新加载之前的渲染结果。

### 下载与手动发布

**微信公众号**

- 「复制富文本」后，在公众号后台编辑器中粘贴，检查图片与样式。
- 或下载 HTML 文件，用浏览器打开后全选复制到公众号编辑器。
- 视频需在公众号后台单独上传并插入（平台限制）。

**小红书**

- 「下载卡片 ZIP」：包含 1080×1440 PNG 卡片、标题与正文文案、笔记 JSON 和原图素材。
- 在小红书 App 发布时，按顺序上传卡片图片，粘贴标题/正文/话题。
- 视频笔记：预览为视频模式，下载原视频与文案后在小红书 App 发布视频笔记。

**知乎**

- 「复制 Markdown」可直接粘贴到知乎编辑器（知乎支持 Markdown 导入），或复制富文本/下载 HTML。
- 视频以播放器形式出现在渲染结果中，正式发布时在知乎编辑器重新上传视频。

**抖音**

- 「复制抖音文案」后粘贴到抖音发布页，标题、正文与话题已整理好。
- 在竖屏预览中确认封面与素材；视频内容建议直接发布视频版本。
- 支持下载文案 TXT、图文 HTML 与笔记 JSON；图片/视频素材会打包进「全部平台 ZIP」。

### 微信公众号自动发布

1. 打开「发布管理」，点击「扫码登录」，使用管理员微信扫码，在手机上选择公众号并确认。系统会加密保存会话，刷新页面和重启服务后可恢复；微信会话过期时重新扫码。
2. 在渲染工作台完成公众号排版并保存调整，点击「发布到公众号」，或在发布管理选择已有渲染记录。
3. 选择或上传封面，检查作者和摘要。「保存草稿」只写入草稿箱；「正式发表」会公开文章，点击前需确认内容。
4. 微信要求安全验证时，扫描发布记录中显示的二维码。页面会自动查询进度，并在核对微信发表记录后提供文章链接。

正式发表不主动开启群发通知。当前自动发布支持图文；视频、音频以及外链图片需先处理为支持的素材。正文中上传到 MultiPush 的图片会自动转存到微信，外链图片请在编辑器重新上传后渲染。原文发生修改后须重新渲染。

遇到「结果待核实」时，先在微信后台检查草稿和发表记录，避免重复发表。断开连接会清除本系统保存的公众号会话；若要撤销全部设备的登录，请在微信安全设置中操作。其他平台继续使用下载后手动发布。

## 5. 常见问题

- **图片在小红书卡片中导出失败**：外链图片可能受跨域限制，建议使用编辑器上传的图片（同源）。
- **复制富文本粘贴后样式丢失**：请使用 Chrome/Edge，并直接粘贴到平台编辑器；部分平台会二次清洗样式。
- **渲染结果中的图片打不开**：确认 MultiPush 服务可访问，且未删除对应上传文件。
- **忘记密码**：当前版本需管理员在数据库中重置（后续版本提供找回密码）。
- **手机访问**：可浏览内容库与渲染结果；编辑器建议使用桌面浏览器。
